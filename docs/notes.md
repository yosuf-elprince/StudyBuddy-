Docker Challenge
أكبر مشكلة واجهتني كانت أن Docker لم يكن يعمل في البداية، لذلك لم أستطع بناء الصورة. بعد تشغيل Docker Desktop والتأكد من عمل Docker Engine بشكل صحيح، تمكنت من بناء الصورة وتشغيل الحاوية بنجاح.
